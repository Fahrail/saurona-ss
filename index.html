Command Reference

Player commands first, staff tools after.

Most commands also appear in game through /help, /commands, and /ss.

Player Essentials

/help Shows the paged player command guide.
/link <code> Links a Minecraft account to Discord.
/stats [player] Shows server stats for yourself or another player.
/mail Opens the inbox with claim and delete buttons.
/mail send Sends a message to another player.
/mail gift Mails the item in your main hand as a gift.

Economy And Storage

/bank Shows bank balance and bank tools.
/dep all Deposits all coins from inventory.
/wdraw <amount> Withdraws coins from the bank.
/transfer Sends bank coins to another player.
/backpack Opens or manages the player's backpack.
/craft Opens a crafting table once unlocked.

Factions And Groups

/faction info Shows faction leader, members, and details.
/faction home Teleports to the faction home.
/faction sethome Lets leaders set the faction home.
/fellowship Manages invites, chat, PvP, ownership, and members.
/fc Short command for fellowship chat.

Playstyle And Progress

/playstyle Checks Haven or Mortal status.
/mortal Starts the Mortal oath confirmation flow.
/abilities Shows unlocked ability uses.
/bounty Views or places Mortal bounties.
/challenges Shows weekly challenge progress.
/playtime Shows active playtime reward progress.
Staff Suite

Moderation and management without leaving the server.

Staff roles are intentionally split: admins and managers get elevated server access, while moderation roles stay focused on moderation work.

ME-BOT

The Discord side of the server.

The bot handles Discord API work while the Minecraft mod remains the source of truth for player identity, punishments, stats, factions, and linked accounts.

Chat Bridge

Discord and Minecraft chat relay with polished embeds for player messages, player events, deaths, command results, and server status.

  • Purple styling for player-facing bridge messages.
  • Gold styling for server state and server command responses.
  • Link blocking that removes blocked links and warns the user.

Account Sync

Players run Discord /link, then finish in Minecraft with /link <code>.

  • Linked Discord role assignment.
  • Minecraft-driven nickname sync.
  • Faction, mute, ban, Haven, Mortal, and Wanderer role mirroring.

Bot Utilities

ME-BOT also carries the Discord-only server tools around the Minecraft bridge.

  • Tickets, transcripts, logs, moderation helpers, and invite tracking.
  • Sticky messages, welcome role/message support, and temporary voice channels.
  • Minecraft stats and game moderation slash commands.
Server Systems

Built for repeated server work.

Mail

Player mail supports text messages, item gifts, clickable inbox actions, new-mail alerts, and login reminders.

Item Cosmetics

Renames default to Saurona gold, lore defaults to gray, and engravings stay at the bottom of item lore.

Inventory Viewing

Staff can view online and offline inventories, ender chests, and backpacks, with unavailable inventory slots blocked visually.

World Extras

Generators, custom traders, music zones, collectibles, weather voting, announcements, recipe controls, and item blacklist tools.

Setup Notes

Build the mod, run the bot, connect both sides.

Requirements

  • Minecraft 1.21.8
  • Fabric Loader 0.19.3 or newer
  • Fabric API for Minecraft 1.21.8
  • Java 21
  • Node.js for ME-BOT

Build Output

The Fabric build creates the server mod jar in:

build/libs/server-side-1.0.0.jar

Discord Connection

Both sides must use the same shared secret. The mod and bot each point their API base URL at the other service.

Minecraft: discordIntegrationSecret ME-BOT: minecraft.sharedSecret
